# 브라우저 수동 점검표 (단위 테스트가 대신하지 못하는 항목)

`python -m http.server 8794` 후 `http://localhost:8794/index.html`. 아래 "기대"는 샘플 PDF 1쪽 기준이며, 단위 테스트 통과는 이 표의 통과를 뜻하지 않습니다.

## 선택 · 하이라이트 (1쪽, 줄: `가상 프로젝트 '열린 책상'은 관객이 일상의 기록을 읽고 대화하는 전시를 제안합니다.`)

| 동작 | 기대 선택 범위 |
| --- | --- |
| 글자 가운데 → 글자 가운데 드래그 | 드래그한 글자 구간만 |
| 줄 시작 왼쪽 5px → 줄 가운데 | 줄 첫 글자(`가`)부터 가운데까지 |
| 줄 가운데 → 줄 끝 오른쪽 5px | 가운데부터 줄 마지막 글자(`.`)까지 |
| 왼쪽 여백 → 오른쪽 여백 (한 줄, 양방향) | 그 줄 전체. 다음 줄로 번지거나 빈 선택이 되면 실패 |
| 줄 가운데 → 다음 줄 가운데 | 두 줄에 걸친 연속 텍스트(`\n` 포함) |
| 왼쪽 여백 → 다음 줄 오른쪽 여백 | 두 줄 전체 |
| 드래그 후 마우스를 떼고 `선택 문장 하이라이트` | 하이라이트 사각형이 선택 글자 위에 생기고 상태 문구에 사각형 수 표시. 버튼 클릭으로 선택이 풀려도 마지막 선택으로 확정 |
| 더블클릭 · Shift+클릭 · 키보드(`예시 문장 선택` 후 Shift+화살표) · 터치 길게 누르기 | 브라우저 기본 선택이 그대로 동작 |

## 정렬 · 표식

- 75/100/125/150% 와 창 크기 변경 뒤에도 하이라이트 사각형과 글자 줄의 차이가 2.3px 안.
- 초성 표식 `가` 는 항상 쪽 오른쪽 여백(점선 연결)에 있고 본문 글자와 겹치지 않는다(1440 · 390, 모든 확대율). 같은 줄 두 개는 아래로 비킨다.
- 표식 클릭 → 연결된 댓글 카드에 포커스, 댓글이 없으면 새 이야기 textarea 로.

## 배치

- 1440 · 1366: 도구줄 한 줄, 오른쪽 패널 ≥500px, 점수 1~10 버튼 한 줄, 상태 문구는 화면에 없고(낭독기용) 오류만 인라인.
- 1024 · 768: PDF 위 · 이야기 아래로 쌓임, 가로 넘침 없음.
- 390: 띠+헤더+도구줄 뒤 PDF 캔버스가 약 220px 안에서 시작, 본문 글자 12px, PDF 영역 안에서만 가로 스크롤(문서 전체 가로 스크롤 없음), `도구` 를 열면 하이라이트 · 예시 · 보기 · 도움말이 나타남. `맞춤` 으로 너비 맞춤 전환.

## 이야기 · 점수

- 빈 입력 · 공백만 → 인라인 오류, 501자 → 입력 자체가 500자에서 멈추고 붙여넣기도 잘림.
- `<img src=x onerror=…>` 같은 문자열을 남기면 글자로만 보이고 실행되지 않는다.
- 탭 `이 쪽(Np)만` 은 쪽을 넘기면 N 과 수가 바뀌고, 전체 문서 댓글은 쪽 탭에 없다.
- 수정 · 답글 · 답글 수정은 카드 안 폼으로, 수정 후에도 `해당 쪽·위치로 이동` 이 같은 하이라이트로 간다.
- 새로고침하면 모든 하이라이트 · 댓글 · 점수가 사라진다(저장 없음).
